Catálogo de Materiais

Códigos SAP · Referências cruzadas · Tudo em um só lugar
* Somente a descrição é obrigatória — dá para cadastrar agora e completar o código SAP depois.

📥 Importar planilha (CSV)

Aceita arquivos exportados do Excel/Google Planilhas ou gerados pelo raspador do Catálogo Expresso. Colunas reconhecidas: codigo_sap, descricao, fabricante, categoria, unidade, referencias, aplicacao, localizacao, observacoes. Materiais com o mesmo código SAP são atualizados (as referências são somadas), os demais são adicionados.

📤 Exportar

Gere um CSV para abrir no Excel ou um backup completo em JSON. Exporte com frequência — os dados ficam salvos apenas neste navegador.

♻️ Restaurar backup JSON

Substitui todos os materiais atuais pelo conteúdo do arquivo de backup.

🗑️ Apagar tudo

Remove todos os materiais deste navegador. Faça um backup antes!
